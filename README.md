# 💊 RECEITUÁRIO PEDIÁTRICO PREMIUM

## 🏥 Descrição

Sistema interativo de prescrições pediátricas com interface moderna, intuitiva e profissional. Desenvolvido para auxiliar profissionais de saúde na geração de recomendações de tratamento pediátrico.

## ✨ Características

- **Interface Responsiva**: Funciona perfeitamente em desktop, tablet e mobile
- **Design Moderno**: Gradiente rosa e vermelho premium
- **Formulário Interativo**: Coleta dados do paciente de forma clara
- **Gerador de Prescrições**: Gera recomendações personalizadas baseadas em diagnóstico
- **14 Diagnósticos Disponíveis**:
  - Febre
  - Tosse
  - Dor de Garganta
  - Dor de Ouvido
  - Diarreia
  - Vômito
  - Constipação
  - Alergia
  - Dermatite
  - Infecção Urinária
  - Pneumonia
  - Bronquite
  - Asma
  - Outro

## 🚀 Como Usar

1. Acesse: **https://iagochaves3-cell.github.io/RECEITA/**

2. Preencha os dados do paciente:
   - Nome completo
   - Idade (0-18 anos)
   - Peso (em kg)
   - Diagnóstico (selecione da lista)
   - Informações adicionais (opcional)

3. Clique em **"🔍 Gerar Prescrição"**

4. A prescrição será exibida com orientações de tratamento

## ⚠️ Aviso Importante

**Este sistema é um auxiliar educacional e informativo.**

- ❌ Não substitui consulta médica profissional

## 🎨 Personalização

O site pode ser facilmente personalizado editando o arquivo `index.html`:

- **Cores**: Modifique `#ff69b4` (rosa) e `#dc143c` (vermelho) nos estilos CSS
- **Diagnósticos**: Adicione novas opções no `<select>` e no objeto `dosageGuides`
- **Dosagens**: Atualize as recomendações de medicamentos conforme necessário
