FAQ

Perguntas frequentes

Como funciona a consulta?

Digite a idade, peso e diagnóstico do paciente. O sistema consulta a base de medicamentos, calcula as doses de forma segura e retorna a prescrição com alertas clínicos.

As doses são calculadas automaticamente?

Sim. As doses são calculadas com base em peso e idade, respeitando limites máximos diários e apresentações disponíveis no Brasil.

Existem alertas de segurança?

Sim. O sistema alerta sobre contraindicações por idade/peso, restrições especiais, interações e outras questões de segurança críticas.

Posso usar isso em emergência?

Este é um sistema de apoio clínico. Para emergências, consulte os fluxos de PALS e protocolos de urgência integrados.

Como atualizam os medicamentos?

A base é revisada continuamente com atualizações de Anvisa, bulas, diretrizes clínicas e evidências. Cada mudança é registrada e rastreável.

Preciso de conexão com internet?

Sim. O sistema funciona online e consulta a base de dados em tempo real. Não há versão offline no momento.
